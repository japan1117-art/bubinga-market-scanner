# Requirements

## Platform premise

- Bubinga本体はブラウザサービスであり、ネイティブアプリ連携を前提にしない。
- Market ScannerはBubingaとは別のPWAとしてChrome等から利用する。
- MVPはBubingaへの自動ログイン、自動発注、画面操作の自動化を行わない。
- データ取得は利用条件を確認できたHTTP APIに限定し、ユーザーID・パスワードをPWAへ保存しない。
- 利用者本人の個人利用に限定し、取得データの第三者共有、販売、商用提供を行わない。
- Productionは認証なしのURLアクセス方式とする。検索エンジンへは`noindex / nofollow / noarchive`を通知するが、URL流出時のアクセス防止を保証するものではない。

## Product goal

Bubingaの取引可能銘柄をペイアウト順に20件まで取得し、選択方向のMAゲートを通過した銘柄をAO・RSI・Stochasticで採点する。60点以上をスコア順に最大5件表示する。自動発注は行わない。

## User flow

1. BULLまたはBEARを選択
2. 「今の相場を分析」を実行
3. 80〜100点を「今すぐチャンス」、60〜79点を「30分以内にチャンス」として全体で最大5件表示

## Acceptance criteria — Issue #1

- スマートフォン幅でBULL/BEAR選択と分析ボタンを操作できる
- 方向選択が視覚・アクセシビリティの両面で識別できる
- 最大5件の結果カードをNOW/SOONに分類できる
- PWA manifestとfaviconを持つ
- スコアが勝率ではない旨を明示する
- 本番ビルドに成功する

## Non-goals

- 自動発注
- MVPでのWebSocket常時接続
- MVPでのチャート表示
- 認証回避、レート制限回避、毎秒REST polling

## Data status

画面、計算エンジン、Bubinga実データ接続を実装済み。未認証HTTP APIの技術的到達性は確認済みだが、公式APIとしての利用許諾、レート上限、将来互換性は未確認である。

## Asset ranking v0.1

- `enabled=true`だけを取引可能候補とする
- 正規化済みpayoutの降順
- 同率の場合はcode昇順、さらに同じならID昇順
- 最大20件。取引可能銘柄が20件未満なら存在する件数のみ返す
- minimum payoutは設定可能だが、初期値は0
- binary/turboの選択はデータ正規化層の責務とし、ランキング層は分離する

## Multi-timeframe scoring v0.2

- 1HのMAは上位環境の方向ゲート。1H反転準備中以上は例外として候補評価を許可する
- 1HのAO/RSI/Stochasticを100点で採点し、良好フェーズは直近4本まで保持する
- 30MのAO/RSI/Stochasticを100点で採点
- 5MのAO/RSI/Stochasticを100点で採点
- 最終点は1H 50% + 30M 35% + 5M 15%
- 明確な1Hトレンドは1Hを最低80%評価し、強い逆転警戒がなければ候補表示の最低60点を確保する
- 反転準備60%、潜在反転80%、反転確認100%、AOの0突破後80%を時間足ごとに適用する
- 1HでAO失速とStochastic逆クロスが成立した終盤は、下位足が良好でも最終69点を上限とする
- AOの0突破後でも、AOの2本連続失速とStochastic逆クロスを優先し40%評価、RSI過熱も伴う場合は30%評価まで下げる
- 5Mまたは30MでAOの2本連続逆行とStochasticの直近逆クロスが同時成立した場合、NOWには分類しない
- 1Hと30Mの両方で同じ強い逆転警戒が成立した場合は候補から除外する
- 80〜100をNOW、60〜79をSOON、59以下を非表示

## Failure handling

- 分析中は方向切替と二重実行を無効化
- network/timeout、HTTP、レスポンス形式不正をユーザー向け文言へ変換
- 生のエラー本文や認証情報を画面へ出さない
- 再試行可能な失敗だけ再試行ボタンを表示
- 部分失敗時は成功した銘柄を表示し、対象数・分析完了数・警告を併記
- 失敗時も直前の成功結果は消さない

## Market noise v0.1

- 既に取得した5分足を再利用し、Bubingaへの追加リクエストなしで計算する
- 1分足ノイズは候補からユーザーが選択した1銘柄だけを追加取得する
- 直近10分を、ヒゲノイズ35%・反転率30%・方向効率の低さ25%・σ異常度10%で参考スコア化する
- ヒゲノイズは、各1分足の全値幅に対して上下ヒゲが占める割合の平均とする
- 値動きが大きくても一方向へ効率よく進む場合は高ノイズとみなさず、ヒゲの多さ・反転・往復による非効率性を優先する
- 1分足結果は次の1分境界までキャッシュし、総合スコアの自動減点には使わない
- 1分OHLCでは1分内の30秒ごとの値動き順序を判定できない旨を表示する
- 短期ノイズは直近6本（30分）、中期ノイズは直近12本（1時間）を対象とする
- 終値方向の反転回数、値動きの効率、選択方向への伸び失敗、レンジ内の往復量から0〜100で評価する
- ノイズ値は高いほど乱高下が強く、低いほど方向性が安定していることを示す
- 初期版は結果カードへの参考表示のみとし、候補抽出・最終スコア・NOW/SOON判定には影響させない
- 各候補の「ノイズを確認」を押した場合だけ詳細を展開し、再度押すと閉じる
- 閾値と配点はバックテストによるCalibration前の暫定値とする
